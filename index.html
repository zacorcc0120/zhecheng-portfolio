从桂北传统民居的生成式参数化工作流，到微信小程序里的时间记录与日常回顾， 再到晶格结构与鼓楼形制的规则提取——对象不同，但都在做同一件事： 把模糊的需求变成可命名、可调整的参数，交给系统去生成，再回到人的判断。

02 / METHODHOW THE WORK IS GENERATED

One pipeline,
four surfaces.

每个项目都从同一套流程出发：把自然语言、数据与场地条件转成可命名、可调整、 可复用的参数，再交给几何或界面去生成，最后回到验证。不同的只是生成的对象。

  1. 01Parametric designGeometry → Rules → Form把几何、构件和尺度关系写成可以调整与复用的规则。
  2. 02AI workflowLanguage → Knowledge → Action将自然语言、领域知识和生成工具连接为可执行的设计流程。
  3. 03Digital productNeeds → Interaction → Feedback把复杂的记录、评估和反馈变成清晰、可操作的产品体验。
  4. 04Computational designParameters → Iteration → Validation用参数、数据与验证，让设计过程可探索，也可被解释。
