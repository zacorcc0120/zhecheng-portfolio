启动方法（Windows）

1. 把压缩包解压到新的文件夹，保留旧版作为备份。
2. 打开能直接看到 package.json、src、public 的文件夹。
3. 点击资源管理器地址栏，输入 cmd，按回车。
4. 输入 npm install，等待完成。
5. 输入 npm run dev。
6. 看到 Ready 后，在浏览器打开终端 Local 显示的地址。
   通常是 http://localhost:3000
7. 在 WORK 中打开 Generative Lattice System。

运行时不要关闭命令窗口。如果旧网站仍在运行，可在旧窗口按 Ctrl+C 停止。
本压缩包包含完整网站，保留此前 RecoveryX、鼓楼和 JIKO 的内容。
