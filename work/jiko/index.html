01 / OVERVIEW

让日常记录成为可以回看的时间轨迹。

JIKO 迹刻是一款围绕时间记录、日常回顾和事项提醒设计的微信小程序。用户可以用圆环计时器记录工作、学习、运动与生活，通过时间轴、每日报告和每周回顾理解时间分配；小迹助手则把自然语言转化为记录、提醒或简单对话。产品采用本地优先的数据策略，并通过微信登录与 CloudBase 完成云端同步。

02 / THE PROBLEM

记录要轻，回顾要有用。

01 / Recording creates friction

传统时间记录需要频繁填写表单。记录动作一旦太重，用户很难在真实生活中持续使用。

02 / Data lacks a narrative

单条计时数据很难回答时间花去了哪里，需要用时间轴、每日记录与周回顾把碎片组织成连续反馈。

03 / Reminders are separated from context

记录与待办通常存在于不同工具。JIKO 尝试让正在发生的事与接下来要做的事处于同一个时间系统。

04 / Personal tools should feel personal

长期使用的记录工具需要适应个人审美与环境，因此提供主题、圆环、壁纸强度和深浅色模式。

05 / 交互与数据设计

围绕记录习惯组织产品。

用计时器承接当下

把圆环计时器放在首页中心，围绕活动类型、开始与暂停组织操作。记录入口服务于正在发生的事，减少开始记录前需要填写的信息。

用不同时间尺度组织回顾

时间轴保留事件顺序，每日记录与周回顾汇总活动分布。同一份记录既能回答“刚才做了什么”，也能帮助回看一段时间的安排。

让自然语言服务具体任务

小迹助手通过 DeepSeek 解析活动和时间信息，服务于记录与提醒。微信订阅消息与定时触发器承接到期通知，AI 能力围绕已有任务展开。

保留本地记录与数据出口

采用本地优先的数据方式，提供导入导出，再通过微信登录与 CloudBase 同步。界面上的记录体验与账户、同步和提醒服务分别承担清晰的职责。

06 / REFLECTION & NEXT STEPS

记录频率、提醒到达率与周回顾仍待验证。

JIKO 从个人需求出发，逐步变成一个完整可运行的小程序。下一阶段需要通过更长周期的真实使用验证记录频率、提醒到达率和周回顾价值，并继续减少创建记录时的操作成本。AI 助手将保持明确边界，优先服务记录与提醒，而不是扩展为无目的的聊天入口。
